# Windows UIA 兼容性与验证

## 本轮验证

- Windows 自检进程实际返回 `unavailable`，未发现 `WeChat.exe` 或 `Weixin.exe`。
- 合成测试覆盖群聊证据与重名拒绝、快照增量与断档、消息字段缺失以及非 Windows 状态。
- 尚未在已登录微信的前台测试群中验证任何客户端版本、消息读取率、端到端延迟或最小化和锁屏行为。

## 识别条件

适配器使用 Windows UI Automation 读取控件属性。只读子进程验证所属进程及顶层窗口。浏览器控制台模式读取前台窗口。悬浮窗模式使用本次明确选中的聊天窗口。群名须在 Sentinel 中手动确认并启用，会话标题须有明确的群控件标识或显示成员数。标题和消息列表须属于同一个可验证的聊天面板，否则本轮受限。首次快照、切换会话及断档会建立基线，后续仅处理有重叠依据的新增文本。缺少明确发送者或带时区原始时间时保存为未知，诊断中仅提供类型和数量。

兼容性取决于当前微信版本暴露的控件语义。未知布局、重名配置、后台窗口、最小化、控件超时和焦点切换都可能显示受限或不可用。可见消息也可能因滚动或界面快速更新漏采。诊断时的“可采集”仅表示本轮已识别并读取到指定群的可见文本控件。

## 悬浮窗选群

点击「添加微信窗口」，在倒计时内将鼠标移到目标微信窗口的标题或空白处。首次探测核对群标题和消息列表结构，并显示待确认的群名。独立聊天窗口还须具有可识别的窗口类型、群身份特征和唯一消息列表。微信 4.x 的适配识别独立群成员数控件，并要求标题和消息列表同属可验证的聊天面板。采集时只从确认的列表读取可见文本。微信可访问树提供稳定会话标识时，持续比较所选会话的标识摘要。缺少稳定标识时，用户须确认群名能够唯一识别。此版参考了公开维护的控件定义，仍需用你当前客户端验证。 [微信 4.x UIA 控件定义](https://github.com/Hello-Mr-Crab/pywechat/blob/main/src/pyweixin/Uielements.py#L633-L640) [文本消息控件定义](https://github.com/Hello-Mr-Crab/pywechat/blob/main/src/pyweixin/WeChatAuto.py#L142-L154)

用户反馈旧版无法识别独立群窗。新版只轮询用户单独确认的可见窗口，最多四个。窗口绑定只在进程内保存。快照、状态和暂停控制按群独立处理。鼠标选窗和可见区域检查使用窗口命中测试，快速遮挡、切换或消息列表虚拟化期间可能漏采。

当前工具无法检测用户桌面上的微信进程。独立窗口选择与多群处理已覆盖合成测试，真实微信入库仍需在用户交互桌面验证。 [独立聊天窗口控件定义](https://github.com/Hello-Mr-Crab/pywechat/blob/main/src/pyweixin/WeChatTools.py#L1405-L1419)

## 微信 4.2.0.52 诊断与本地 OCR 原型

两轮真机报告在同一独立群窗找到了微信进程。常规 UIA 与原始 UIA 树均返回一个窗口和两个面板，指向测试文本时只定位到窗口，MSAA 返回窗口客户区。用户随后确认用本地 OCR 试读手选的可见区域。使用 OCR 便携包内的 `WeChatSentinel.exe` 或 `Start-Sentinel-OCR.cmd`，看到「框选微信窗口」即可开始。原型当前支持单群，真实微信 OCR 的采集率仍需要逐条验收。

## 真机测试清单

1. 关闭微信，运行 `scripts/diagnose.ps1`，记下诊断结果，再确认 Mock 仍可演示。
2. 登录微信并用有权处理的测试群。配置唯一群名、自定义会话标识、启用状态和规则，然后在「诊断与设置」明确启用 UIA。将微信保持前台，停在目标群最新消息处。
3. 等待至少一次快照。用另一个已授权客户端逐条发送 10 条带序号的合成文本，间隔至少一个轮询周期。记录收到的序号、条数、采集时间与延迟。
4. 分别在另一未打开的测试群、目标窗口最小化和锁屏时重复。记录各条件的状态与可读数量。未观测到的消息标记漏采。
5. 关闭并重启 Sentinel，确认数据仍可查询、启动来源回到 Mock。重新启用 UIA 后，当前可见消息应先建立基线。

控制属性说明参见 [Microsoft UI Automation 属性文档](https://learn.microsoft.com/en-us/windows/win32/winauto/uiauto-propertiesforclients) 和 [pywinauto UIA Element Info](https://pywinauto.readthedocs.io/en/latest/code/pywinauto.uia_element_info.html)。
